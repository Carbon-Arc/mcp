# Carbon Arc MCP Server

Hosted Model Context Protocol (MCP) server for the Carbon Arc Insights Platform.

| | |
|---|---|
| **Endpoint** | `https://mcp.carbonarc.ai` |
| **Transport** | Streamable HTTP |
| **Auth** | OAuth 2.0 + Dynamic Client Registration |
| **Documentation** | <https://docs.carbonarc.ai/platform/mcp> |
| **Support** | <support@carbonarc.ai> |
