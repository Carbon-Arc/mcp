# Carbon Arc MCP

- **Endpoint:** `https://mcp.carbonarc.ai` (Streamable HTTP)
- **Auth:** OAuth 2.0 + Dynamic Client Registration
- **Docs:** <https://docs.carbonarc.ai/platform/mcp>

## Install via Cursor

1. Open Cursor → **Plugins** → **Browse Marketplace**
2. Search "Carbon Arc" → **Install**
